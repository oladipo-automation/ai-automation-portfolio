🔷 1. Company Data Enrichment System

Tools: Make.com + AbstractAPI + Google Sheets + Airtable

📌 What It Does
	•	Retrieves company domains from Google Sheets
	•	Sends GET requests to AbstractAPI Company Enrichment
	•	Extracts metadata:
	•	Industry
	•	Size
	•	Location
	•	Logo
	•	Tech stack
	•	Updates enriched details in Airtable Business Leads Table

🔧 Skills Demonstrated
	•	API requests (GET)
	•	JSON parsing and data mapping
	•	Make database search + Airtable record updating
	•	Automation architecture (Sheets → API → Airtable)

  🔷 2. Support Ticket Classifier & Routing System

Tools: Zapier + Zapier AI + Postman + Google Sheets

📌 What It Does
	•	Postman simulates website sending JSON complaint to Zapier Webhook
	•	Zapier AI classifies issue:
	•	Billing
	•	Technical
	•	Account Access
	•	Zapier AI generates the response message
	•	Sends complaint to the correct team
	•	Logs to Google Sheets
	•	Sends 24-hour reminder for unresolved tickets

🔧 Skills Demonstrated
	•	Webhook ingestion
	•	AI classification and message generation
	•	JSON → structured data mapping
	•	Conditional routing (Paths)
	•	Delay automation for follow-ups
